# AntCraft

A Fabric mod for Minecraft 26.3 that turns the world into an ant farm: a strip only **20 blocks wide and 300 blocks long** that goes almost **2,000 blocks down**. You start on a normal surface and have to dig your way to the End portal at the very bottom, layer by layer.

## Features

- **The strip world**: a new world type, *AntCraft Strip*, with invisible walls along the edges. Width and length are configurable for new worlds.
- **8 deep layers**, each separated by a bedrock floor with exactly **one hole**:

  | Layer | Name | Notes |
  |---|---|---|
  | 1 | Oak Hollow | coal and copper |
  | 2 | Taiga Deep | + iron |
  | 3 | Darkwood Caverns | + gold |
  | 4 | Jungle Grotto | + redstone and lapis |
  | 5 | The Deep Dark | + diamond, ancient city |
  | 6 | Buried Desert | + obsidian and emerald, buried desert pyramid |
  | 7 | Mangrove Mire | + ancient debris |
  | 8 | Mushroom Abyss | End portal room at the very bottom |

- **Underground forests** in every layer, with ponds, plants, animals, climbable vines on the walls and enough light for crops and saplings. Crops grow faster down there.
- **Villages** in most layers. The deeper the village, the better its villagers trade.
- **Gates**:
  - **Boss rooms** on floors 0, 2 and 6. Press the button to fight the guardian; when it dies, the way down opens and a teleporter back up appears.
  - **Floor 4** is sealed. A **Nether Key** from the Nether opens it.
  - **Floor 7** is sealed. An **Ancient Key** from the ancient city opens it.
- **Harder rock, harder mobs**: stone takes longer to mine the deeper you go. More monsters spawn deeper down, and zombies there are better equipped.
- **Nether and End strips**: the Nether is a strip too (1:1 with the overworld), with a fortress, a bastion and the Nether Key shrine. The End is a strip with the dragon fight kept inside the walls.
- **Layer titles and advancements**: an *AntCraft* advancement tab, and a title whenever you enter a new layer.
- **Updates for existing worlds**: chunks generated by an older AntCraft are upgraded when they load. Only open air is filled in, so your builds are left alone.

## Installing

1. Install [Fabric Loader](https://fabricmc.net/use/) 0.20.1 or newer for Minecraft 26.3.
2. Put these in your `mods` folder:
   - the AntCraft jar from the [latest release](https://github.com/HugoDijkstra/antcraft/releases/latest)
   - [Fabric API](https://modrinth.com/mod/fabric-api)
   - optional: [Mod Menu](https://modrinth.com/mod/modmenu), for the config screen
3. Create a new world and choose **World Type → AntCraft Strip**.

On a dedicated server, set `level-type=antcraft\:strip` in `server.properties` before the world is created.

## Configuration

`config/antcraft.json`, or in game with Mod Menu → AntCraft:

| Setting | Default | |
|---|---|---|
| `stripWidth` / `stripLength` | 20 / 300 | strip size for new worlds |
| `miningHardnessPerLayer` | 0.5 | extra mining time per layer (0 = off) |
| `layerTitles` | true | titles when entering a layer |
| `spawnMobsNearPlayers` | true | mobs spawn near your height, more of them deeper down |
| `guardians` | true | boss rooms on floors 0, 2 and 6 |
| `netherKeyGate` / `ancientKeyGate` | true | the sealed floors 4 and 7 |
| `autoUpdate` | true | download new releases from GitHub on start |

## Auto-update

Every push to `master` is built by GitHub Actions and published as a release (version `1.0.<commit count>`). With `autoUpdate` on, the mod checks the latest release when the game starts. If there's a newer one, it downloads the jar, checks it against the release's SHA-256 checksum, and installs it for the next start. You get a chat message when that happens.

## Building

Requires JDK 25 or newer.

```sh
./gradlew build
```

The jar ends up in `build/libs/`. Run `./gradlew test` for the geometry unit tests, and `tools/worldcheck.sh` for an in-game world self-check on a test server.
